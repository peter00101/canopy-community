# 06 · 质检

两道闸：**结构自检**（对着文件逐条判定，不靠感觉）和**视觉复核**（截图亲眼看）。前 3 页写完先过一次结构自检，全部写完再过一次全套。

## 结构自检清单（逐页、逐条打钩）

| # | 检查项 | 怎么判 |
|---|---|---|
| 1 | 只用了契约允许的元素 | 搜文件里有没有 `foreignObject` `style` `filter` `mask` `use` `class=` `style=`，有就改 |
| 2 | 边界 | 每个元素 `x ≥ 40`、`y ≥ 40`、`x+w ≤ 1240`、`y+h ≤ 680`；页脚允许到 700 |
| 3 | 不重叠 | 同层卡片矩形两两不相交；文字所在矩形不跨出它的卡片 |
| 4 | 字号下限 | 标题 ≥ 36、卡片标题 ≥ 24、正文 ≥ 18、标签 ≥ 14；一页不超过 4 种字号 |
| 5 | 每行字数 | 按 04 的字宽表算：可用宽度 ÷ 100 × 系数，向下取整再减 1，超出就断行或删字 |
| 6 | 文本块高度 | 行数 × 字号 × 1.4 ≤ 所在卡片高度 − 上下内边距 |
| 7 | 密度 | 正文 ≤ 80 汉字；视觉元素 ≥ 2 种；标题 ≤ 16 字 |
| 8 | 对比度 | 文字色与所在底色：正文 ≥ 4.5:1，大标题 ≥ 3:1。深底浅字或浅底深字，不要中灰压中灰 |
| 9 | 转义 | 文本里的 `&` `<` `>` 已写成实体；属性值里没有裸引号 |
| 10 | id 唯一 | `clipPath` / 渐变的 id 带页码前缀，全份不重复 |
| 11 | 数据一致 | 页面上的每个数字都能在 `outline.json` 的 `content` 里找到，且单位一致 |
| 12 | 一致性 | 页脚、页码、标题位置、装饰元素与前几页相同；同类页型结构相同 |

对比度速算：用相对亮度 L = 0.2126R + 0.7152G + 0.0722B（各通道先做 sRGB 线性化），对比度 = (L亮 + 0.05) ÷ (L暗 + 0.05)。记不住就用风格卡给的 `text` / `muted` 压 `bg` / `surface`，这些组合都过 4.5。

## 视觉复核（联系表）

合成后先 `mkdir -p <绝对路径>/qa`，再 `OfficeInspect mode=screenshot grid=4 outPath=<绝对路径>/qa/contact.png`。

- 能看图的模型：`Read` 打开联系表，逐页看下面七项。
- 看不了图的模型（DeepSeek 等纯文本模型）：调用 `VisionRelay`，`imagePath` 指向联系表，`instruction` 写成「这是一份 N 页 PPT 的联系表，按 p01～pNN 逐页检查以下七项，每项写通过或问题所在页与位置：…」把七项原样列进去；拿到回答后只修它点名的页。`VisionRelay` 不存在或报错，就只做结构自检，README 写明「未做视觉复核」。
- 截图报错：把错误原文记进 README，跳过视觉复核。**不要**改用别的渲染器、不要自建 HTML 预览。

七项：

1. 图片清晰、没有拉伸变形。
2. 文字没有压在人脸、产品、Logo 上。
3. 所有元素在页面内，没有被切掉半个字。
4. 文字与底色、相邻色块之间对比够。
5. 同类元素对齐：标题左缘一条线，卡片顶边一条线，页脚一条线。
6. 文字没有溢出卡片，没有一行挤成两行的错觉（截图里断行位置与预期一致）。
7. 没有元素被上层遮住。

可疑的页再 `page=N` 单独截图放大看。截图是 Chromium 渲染，与 PowerPoint 的差别主要在字体宽度，所以第 5 条字数控制留了余量；截图里已经溢出的，PowerPoint 里一定溢出。

## 修一页只动一页

1. 改 `slides/pNN.svg`，重新过该页的结构自检。
2. 一个 `OfficeBatch`：`remove /slide[N]/picture[1]`，再 `add` 新图片（参数同首次合成）。路径不确定时先 `OfficeInspect mode=query selector=picture` 看真实路径。
3. `OfficeInspect mode=screenshot page=N` 复核这一页。
4. 不重做其它页，不改 `design.json`。

## 常见失败与根因

| 现象 | 根因 | 修法 |
|---|---|---|
| 整页空白 | 文本里有未转义的 `&` / `<`，或用了 `style` 标签 | 转义；改表现属性 |
| 文字被切 | 一行字数超字宽表 | 断行或减字 |
| 卡片顶到页脚 | 文本块高度没算 | 减行或增高卡片 |
| 颜色发灰看不清 | 中灰压中灰 | 换风格卡里的配对色 |
| 图片糊 | 原图小于目标框 | 缩小目标框或换图 |
| 圆角图片没圆角 | `clip-path` 的 id 与别页重名 | id 加页码前缀 |
| 联系表里某页字体不同 | 该页字体栈写错 | 复制骨架里的字体栈 |
