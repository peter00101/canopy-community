# 01 · 调研

## 目标

给大纲提供**可引用的事实**：数据、时间、原话、对比。调研笔记不是正文，正文只写提炼后的结论。

## 三个档位

| 档位 | 什么时候用 | 来源数 | 工具 |
|---|---|---|---|
| 不调研 | 用户材料已足够；内部事务（周报、复盘、制度） | 0 | 无 |
| 轻量 | 有材料但需要市场 / 行业 / 数据背景 | 6～10 条摘要 | `WebSearch`，不可用时用内置浏览器搜必应 |
| 深度 | 主题型 PPT、行业分析、竞品对比、政策解读 | ≤12 个来源全文 | 内置浏览器逐个打开读正文 |

预算上限：深度档最多 12 个来源，每个来源抽正文不超过 3000 字，总耗时超过约 10 分钟就停下先出大纲。

## 工具怎么选

1. `WebSearch` / `WebFetch` 只有用户配了搜索 Key 才会出现在工具列表里。**列表里没有就别等，直接走浏览器。**
2. MCP 目录里的 Exa、Tavily、Brave 搜索若已连接，同样可用，优先级与 `WebSearch` 相同。
3. 浏览器路径（零 Key，任何模型可用）：
   - `BrowserNavigate` 打开 `https://cn.bing.com/search?q=<查询>`；
   - `BrowserExtract` 抽结果列表，挑 3～5 条相关链接；
   - 逐个 `BrowserNavigate` 打开，`BrowserExtract` 抽正文（优先给 selector，如 `article`、`main`）；
   - 需要留档时 `BrowserExportPdf` 存到 `research/sources/`。
   - 登录后才能看的站点由用户先在浏览器里登录，再让 Agent 读；不要替用户输入密码。

## 查询拆解

主题拆成 3～5 个角度，每个角度 1～2 条查询：

- 现状与规模（数据、增长率、市场份额）
- 关键变化与趋势（近 12 个月）
- 主要参与者 / 竞品 / 方案对比
- 风险、争议、监管
- 案例与原话（可引用的一句话）

中文主题同时搜一条英文查询，数据类主题优先找官方统计、上市公司公告、行业报告摘要。

## 笔记格式 `research/notes.md`

```markdown
# 调研笔记 · <主题>
调研日期：2026-09-13 · 档位：深度 · 来源 8 个

## 来源
[S1] 标题 — URL — 访问日期
[S2] …

## 事实卡
- [S1] 2025 年市场规模 1,280 亿元，同比 +12%（原文：「……」）
- [S3] 头部三家份额合计 61%
- [待核] 某机构预测 2027 年翻倍——来源二手，未找到原始报告

## 可用原话
- [S2] 「……」——某某，职务
```

规则：

- 每条事实前缀来源编号，找不到来源的写「待核」，大纲不得把待核项当事实用。
- 数字保留单位与口径（人民币 / 美元、年度 / 季度）。
- 原话逐字，不改写。
- 相互矛盾的数据都记下来，并注明取哪个、为什么。

## 交给大纲什么

大纲阶段只读 `research/notes.md` 的「事实卡」和「可用原话」两节，每页的 `sources` 填编号。交付 README 的「来源」一节直接复制「来源」清单。
