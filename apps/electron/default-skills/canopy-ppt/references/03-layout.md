# 03 · 便当网格与页型

## 便当网格（Bento Grid）

内容驱动布局，不套死模板。把一页拆成若干张卡片，用卡片尺寸表达层级：最重要的信息放最大的卡片。

- 卡片数量不固定：1、2、3、4、5 或更多，取决于内容需要，不为凑数加卡片。
- 层级感：一页只有一个视觉焦点；次要信息用小卡片或无卡片的纯文本。
- 留白：卡片之间至少 20px；页面四周至少 40px；标题区与内容区之间至少 24px。
- 对齐：所有卡片落在 12 列栅格上（列宽 80px，列间距 20px，左右各留 40px），卡片高度按内容取整到 20px 的倍数。

### 组合范例（坐标按 1280×720，标题区占顶部 0～120px）

| 组合 | 适用 | 卡片矩形 x,y,w,h |
|---|---|---|
| 单一焦点 | 一句有力结论、一张大图表 | 40,140,1200,540 |
| 两栏对称 | 对比、前后 | 40,140,590,540 · 650,140,590,540 |
| 两栏非对称 | 主内容 + 辅助数据 | 40,140,790,540 · 850,140,390,540 |
| 三栏并列 | 三个并列要点 | 40,140,386,540 · 447,140,386,540 · 854,140,386,540 |
| 主次结合 | 一个核心 + 两侧补充 | 40,140,280,540 · 340,140,600,540 · 960,140,280,540 |
| 顶部英雄式 | 一句结论 + 3～4 个支撑数字 | 40,140,1200,260 · 下方 3～4 张 40+i×305,420,285,260 |
| 混合网格 | 内容形态多样 | 自由组合，但每张卡片必须落在栅格线上 |

## 页型起点（十二种，可照抄、可混搭、可另起）

另起新页型（共创模式里常见）：先在回复里写清结构——几块、主次、各放什么数据——再动手写 SVG；密度与间距硬规则照过，同类页型在整份里保持一致。

| 页型 | 对应 `visual` | 要素 | 起点组合 |
|---|---|---|---|
| 封面 | cover | 主标题、副标题、日期 / 单位、一处装饰 | 无卡片，标题区放大到左下或居中 |
| 目录 | toc | 3～6 个部分名，序号 | 单列或两列序号卡 |
| 章节页 | section | 大序号 + 部分名 + 一句引导 | 单一焦点，留白多 |
| 要点页 | list | 3～5 条要点 | 单一焦点内做条目，或三栏并列 |
| 关键数字 | kpi | 2～4 个数字，各带标签与变化 | 顶部英雄式或三栏 |
| 两栏对比 | compare | 左右各一组要点 | 两栏对称，标题行标出「A vs B」 |
| 流程 | process | 3～5 步，箭头相连 | 横向等宽卡片 + 箭头 |
| 时间线 | timeline | 3～6 个节点 | 横向轴线 + 节点圆点 + 上下交错说明 |
| 图表 | chart | 一张 SVG 图形 + 一句解读 | 两栏非对称，图占宽栏 |
| 表格 | table | ≤5 列 × ≤6 行 | 单一焦点内画表格线 |
| 引言 | quote | 一句原话 + 出处 | 单一焦点，大字号 |
| 图片主导 | image | 一张用户图片 + 一句说明 | 两栏非对称，图占宽栏，或满版图压暗加字 |
| 总结 | end | 3 条结论 + 1 条行动 | 顶部英雄式 |

## 密度与间距硬规则（结构自检要逐条过）

1. 每页正文（不含标题、标签、页脚）不超过 80 个汉字或 60 个英文单词。
2. 每页至少两种视觉元素（卡片、数字、图形、图标、图片、表格线、时间轴任取其二）；封面和章节页例外。
3. 标题不超过 16 个汉字；一页只有一个标题。
4. 所有元素满足 `x ≥ 40`、`y ≥ 40`、`x + w ≤ 1240`、`y + h ≤ 680`；页脚 / 页码可放在 `y = 680～700`。
5. 卡片间距 ≥ 20px；标题区底边与首个内容元素顶边间距 ≥ 24px。
6. 字号下限：标题 ≥ 36，卡片标题 ≥ 24，正文 ≥ 18，标签 / 页脚 ≥ 14；一页内不超过 4 种字号。
7. 同一行文字不超过其卡片宽度能容纳的字数（见 04 的字宽表），超出必须断行或删字。
8. 文本块高度 ≥ 行数 × 字号 × 1.4，不允许文字贴着卡片底边。
9. 图片主导页的图片裁切后必须保持原始比例，不拉伸。
10. 同一份 PPT 里同类页型的结构保持一致：目录、章节页、总结页各自只用一种样式。

## 视觉焦点设计法

写每页 SVG 前，先用一行草稿定下：

```text
p05 · kpi · 顶部英雄式 · 焦点：营收 1.28 亿 · 支撑：毛利率、新签、续约率 · 数据来源 S1 S2
```

草稿写在回复里，然后再写 SVG。焦点元素的字号是次要元素的 2 倍以上；颜色用 `accent`，其余用 `text` 与 `muted`。
